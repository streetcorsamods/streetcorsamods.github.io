| Problema | Solução |
|---|---|
| O jogo pede a **pasta do Assetto Corsa** | Escolha a pasta onde está o `AssettoCorsa.exe`. Para trocar depois: **Settings → Assetto Corsa folder**. |
| **"Runtimes Missing"** ou sem 3D | Instale os runtimes do [Visual C++](https://aka.ms/vs/17/release/vc_redist.x64.exe) e do [DirectX](https://www.microsoft.com/download/details.aspx?id=8109), reinicie. |
| A corrida não começa: **Custom Shaders Patch is not installed** | Instale o [CSP](https://acstuff.club/patch/). |
| **"Race Never Started"** | O modo de corrida não carregou no AC. Nada foi perdido. Atualize o CSP; o `Documents\Assetto Corsa\logs\custom_shaders_patch.log` diz o motivo. |
| Sinal de alerta na tela principal | Clique nele: o Custom Shaders Patch está faltando ou é antigo demais. Atualize pelo Content Manager. |
| A corrida não começa: **races need 0.2.11 or newer** | Atualize o CSP pelo Content Manager (Settings → Custom Shaders Patch). |
| **"Assetto Corsa is already running"** | Feche o Assetto Corsa (e o jogo do Content Manager) e tente de novo. |
| **"Mod Problems"** | Um mod está quebrado ou é antigo demais. O resto do jogo funciona; atualize ou remova esse mod. |
| O carro não corre | Abra **Repairs**: lá diz o motivo (sem combustível, motor quebrado, falta uma roda...). |
| A polícia nunca aparece | Instale um carro de polícia no Assetto Corsa. |

## Onde fica cada coisa

- Saves, configurações, log: `%AppData%\StreetCorsa`
- Mods: a pasta `Content` na pasta de instalação do jogo
- Músicas do rádio: `Documents\Street Corsa\Radio` (mp3, ogg, flac). Aperte **F2** para o rádio.

Ainda travado? Mande o log (`%AppData%\StreetCorsa\Logs`) junto com o seu relato.
