**Early access:** version 0.1.0 is the first public one, with work ahead. Saves may not carry over to later versions.

1. Install **the game**.
2. Add a **setting**: on the main screen, **Mod Manager → Install mods**, pick the zip.
3. Engine packs and add-ons install the same way.

Full steps: [Install](/tutorials/playing/install/).
