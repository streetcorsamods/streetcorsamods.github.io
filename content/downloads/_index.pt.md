**Acesso antecipado:** versão 0.1.4, com trabalho pela frente. Os saves podem não passar para versões futuras. O que mudou: o [changelog](/about/changelog/) (em inglês).

1. Instale **o jogo**.
2. Adicione um **cenário**: na tela principal, **Mod Manager → Install mods**, escolha o zip.
3. Pacotes de motores e complementos se instalam do mesmo jeito.
